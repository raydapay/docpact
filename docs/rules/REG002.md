# REG002 — Tool-registry entry names no function in the same file

**Namespace:** `REG`  
**Severity:** ⚪ off (opt-in)  
**Fix:** No automatic fix

---

## Description

A coverage-visibility diagnostic, **off by default**. When a tool-registry
entry's `name` matches no function defined in the same file, docpact cannot
cross-check it: the function is presumably registered from another module (the
cross-file pattern that the same-file `REG` rules treat as out of scope, ADR-005).
By default such an entry is silently skipped, keeping the per-file boundary honest
without noise.

Teams that want to audit how much of their registry is actually backed by a
same-file function can opt in by raising REG002's severity. It then flags every
entry whose target is elsewhere — useful for spotting a typo'd `name`, or for
inventorying which tools are defined out-of-module (candidates for `--crossfile`).

REG002 carries `default_severity = off` because docpact has only ERROR / WARNING /
OFF severities (no INFO tier); `off` is how "present but silent until opted into"
is expressed.

## Examples

### Triggering — entry whose `name` matches no same-file function (when enabled)

```python
def search_cases(query: str) -> list:
    """Search cases."""
    ...


TOOLS = [
    {"name": "search_caes", "parameters": {"properties": {"query": {}}}},  # typo: no such function
]
```

With `REG002 = "warning"`:

```
tools.py:7:4: REG002 Tool-registry entry 'search_caes' matches no function in this file; cross-file registration is not cross-checked
```

This also fires for a *legitimately* imported handler — registering a function
defined in another module is the intended trigger for the audit, not a bug:

```python
from handlers import search_cases   # defined elsewhere

TOOLS = [{"name": "search_cases", "parameters": {"properties": {"query": {}}}}]
# REG002 (if enabled): 'search_cases' is registered but not defined here.
```

### Passing — entry backed by a same-file function

```python
def search_cases(query: str) -> list:
    """Search cases."""
    ...


TOOLS = [{"name": "search_cases", "parameters": {"properties": {"query": {}}}}]
```

## Configuration

REG002 ships off. Enable it by raising its severity (and selecting `REG`):

```toml
[tool.docpact]
select = ["DOC", "REG"]

[tool.docpact.rules]
REG002 = "warning"   # or "error"
```

Suppress a specific entry inline, on its line:

```python
TOOLS = [
    {"name": "remote_tool",  # nodo: REG002 -- registered from the plugins package
     "parameters": {"properties": {}}},
]
```
