# FIX004 — Suppression comment is not on a `def` keyword line; will be silently ignored

**Namespace:** `FIX`  
**Severity:** 🟡 warning  
**Fix:** No automatic fix

---

## Description

docpact matches suppression comments by the line of the `def` keyword
(`func.line`). A `# nodo: CODE -- reason` placed on any other line is still parsed
into the suppression map but **silently ignored**: nothing is suppressed, and the
original violation keeps firing. FIX004 catches this dead-comment trap so a
suppression you believed was active does not quietly fail.

The most common cause is ruff's formatter. When it wraps a long function
signature, it moves a trailing comment from the `def` line down to the closing
`) -> Type:` line. To survive reformatting, place the suppression right after the
opening parenthesis:

```python
def foo(  # nodo: DOC012 -- reason   ← correct: on the def line
    arg: str,
) -> None: ...
```

not:

```python
def foo(
    arg: str,
) -> None:  # nodo: DOC012 -- reason   ← ruff puts it here; silently ignored
```

A suppression is considered correctly placed when it sits on a `def` keyword
line, an `async def` keyword line, a `class` keyword line, or line 1 (module
level, for [DOC002](DOC002.md)). Any other placement is flagged. When the
misplaced line looks like a wrapped-signature close (`) -> ...`), the message adds
a hint that ruff likely moved it.

This is a file-level rule with no auto-fix: relocating the comment to the right
line is left to the author (or to re-running ruff after moving it).

## Examples

### Triggering

```python
def fetch(
    query: str,
) -> list:  # nodo: DOC012 -- reason
    """Fetch matching rows."""
```

```
mod.py:3:12: FIX004 Suppression comment is not on a `def` keyword line; it will be silently ignored (looks like ruff moved it from the `def` line to the closing `) -> Type:` line)
```

### Passing

```python
def fetch(  # nodo: DOC012 -- reason
    query: str,
) -> list:
    """Fetch matching rows."""
```

## Configuration

This rule can be disabled with:

```toml
[tool.docpact]
ignore = ["FIX004"]
```

Or suppressed inline (which must, of course, be on the `def` keyword line):

```python
def my_function(  # nodo: FIX004 -- reason
    ...
```
