# REG011 — Tool declares a parameter its imported handler does not accept

**Namespace:** `REG`  
**Severity:** 🟡 warning  
**Fix:** No automatic fix

---

## Description

Cross-file rule (ADR-010) — the cross-file analogue of REG001. A tool-registry
entry that names an **imported** function as its `handler` declares a set of
parameters: the JSON-schema `properties` keys when present, otherwise the fields
of its imported `input_model`. REG011 fires when a declared parameter is not
accepted by the imported handler's signature — typically a model field or schema
key renamed without updating the handler (or vice versa).

The handler is resolved to its defining file via a language server
(`[tool.docpact.lsp]`, default `ty`); docpact reads the signature by its own
static AST pass. Like REG001 it is **phantom-direction only** — a signature
parameter that is *not* declared is legitimate non-exposure (see reserved
REG003), not a finding.

Two guards keep it low-false-positive:

- **Model-instance handlers are skipped.** If the handler takes the model as a
  single typed parameter (`def handler(payload: SearchInput)`) rather than
  unpacked fields, no field-by-field comparison applies.
- **`**kwargs` handlers are skipped.** A handler accepting arbitrary keyword
  arguments accepts any declared parameter.

**Runs only under `docpact check --crossfile`** and only when `REG` is in
`select`. An unresolvable handler is skipped; a missing/failing server degrades
gracefully.

## Examples

Cross-file: the handler and the registry live in different modules.

### Triggering — handler does not accept a declared field

```python
# schemas.py
class SearchInput(BaseModel):
    query: str
    limit: int
```

```python
# handlers.py
def search_cases(query: str) -> list[Case]:   # accepts 'query' only
    ...
```

```python
# tools.py
from handlers import search_cases
from schemas import SearchInput

TOOLS = [
    ToolDefinition(name="search", handler=search_cases, input_model=SearchInput),
]
```

Run with `docpact check . --crossfile` (and `REG` selected):

```
tools.py:5:4: REG011 tool 'search' input model declares parameter 'limit', which imported handler 'search_cases' does not accept
```

### Passing — handler accepts every declared parameter

```python
# handlers.py
def search_cases(query: str, limit: int) -> list[Case]:
    ...
```

### Passing — handler receives the whole model (guarded)

```python
# handlers.py
def search_cases(payload: SearchInput) -> list[Case]:   # single typed param → skipped
    ...
```

## Configuration

```toml
[tool.docpact]
select = ["DOC", "REG"]   # REG011 needs the REG namespace

[tool.docpact.lsp]
server = ["ty", "server"]
```

```bash
docpact check src/ --crossfile
```

Disable it specifically:

```toml
[tool.docpact]
ignore = ["REG011"]
```

Or suppress inline, on the registry entry's line:

```python
TOOLS = [
    ToolDefinition(name="search", handler=search_cases,  # nodo: REG011 -- handler unpacks via **kwargs at runtime
        input_model=SearchInput),
]
```
