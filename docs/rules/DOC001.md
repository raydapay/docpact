# DOC001 — Function missing a required docstring

**Namespace:** `DOC`  
**Severity:** 🔴 error  
**Fix:** Safe fix available (`--fix`)

---

## Description

Fires when a function or method that requires a docstring has none. All tiers require at minimum a one-sentence summary, so DOC001 fires regardless of tier.

The `--fix` flag inserts a tier-appropriate stub immediately after the function signature. The stub contains `[FILL]` markers for each element that needs content — summary, Args entries, Returns, and for Tier 3+ functions also Raises, Constraints, Stability, and MCP sections. The stub immediately triggers DOC099 (placeholder not replaced), which prevents the stub from silently passing the pipeline without being completed.

`self` and `cls` are excluded from the generated Args section. `*args` and `**kwargs` are included only when the function's tier requires full Args documentation.

## Examples

### Triggering

```python
def transfer_funds(account_id: str, amount_cents: int) -> dict:
    # No docstring — DOC001 fires
    return _process(account_id, amount_cents)
```

### Passing

```python
def transfer_funds(account_id: str, amount_cents: int) -> dict:
    """Transfer funds between accounts.

    Args:
        account_id: UUID of the source account. Must exist and be active.
        amount_cents: Amount to transfer in cents. Must be positive.

    Returns:
        Transfer receipt with confirmation_id and settled_at timestamp.
    """
    return _process(account_id, amount_cents)
```

### After `--fix` (stub inserted; DOC099 fires until filled)

```python
def transfer_funds(account_id: str, amount_cents: int) -> dict:
    """[FILL: single-sentence summary in imperative mood]

    Args:
        account_id: [FILL]
        amount_cents: [FILL]

    Returns:
        [FILL]
    """
    return _process(account_id, amount_cents)
```

## Rationale

A missing docstring is the most visible form of documentation debt. For agent-facing code, a function with no docstring leaves callers with no signal about what to pass, what to expect, or what can fail. The safe fix makes starting cheaper than skipping — the stub is a scaffold, not a finished product.

## Configuration

Disable globally:

```toml
[tool.docpact]
ignore = ["DOC001"]
```

Disable per file:

```toml
[tool.docpact.per-file-ignores]
"src/internal/*" = ["DOC001"]
```

Suppress inline (on the `def` line):

```python
def _cache_key(  # nodo: DOC001 -- private helper, no external callers
    parts: list[str],
) -> str: ...
```
