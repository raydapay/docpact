# DOC012 — Required docstring section missing for function tier

**Namespace:** `DOC`  
**Severity:** 🔴 error  
**Fix:** No automatic fix

---

## Description

Fires when a function has a docstring but is missing one or more sections required by its tier. Tier requirements are:

| Tier | Required sections |
|---|---|
| 1 | Summary only (no section requirements) |
| 2 | Args (when parameters present), Returns (when return annotation is non-None) |
| 3+ | Same as Tier 2, plus Raises, Constraints, Stability, and MCP |

For the MCP section at Tier 3+, either a docstring `MCP:` section or a decorator `description=` argument satisfies the requirement — both are accepted.

Sections that use the canonical empty form (`None.`) satisfy the requirement. A section that is entirely absent triggers DOC012. DOC013 handles the case where a section exists but uses a non-canonical empty form.

Tier assignment is automatic from decorators and file structure. See the [tier model](../../README.md#tier-model) for details. Overrides are available via config when automatic assignment does not fit.

No fix is available: the correct section content cannot be inferred without semantic understanding of the function.

## Examples

### Triggering — Tier 2 function missing Returns

```python
def get_user(user_id: str) -> dict:
    """Fetch a user record by ID.

    Args:
        user_id: UUID of the user to fetch.

    # Returns section missing — DOC012 fires
    """
```

### Triggering — Tier 3 MCP tool missing Constraints and Stability

```python
@mcp.tool
def send_message(channel: str, text: str) -> str:
    """Send a message to a channel.

    Args:
        channel: Slack channel name, including the # prefix.
        text: Message text. Markdown supported.

    Returns:
        Message timestamp.

    Raises:
        SlackAPIError: If the channel does not exist or the bot lacks access.

    # Constraints and Stability sections missing — two DOC012 diagnostics fire
    """
```

### Passing — Tier 3 with all required sections

```python
@mcp.tool
def send_message(channel: str, text: str) -> str:
    """Send a message to a channel.

    Args:
        channel: Slack channel name, including the # prefix.
        text: Message text. Markdown supported. Max 40,000 characters.

    Returns:
        Message timestamp (Slack ts format, e.g. "1234567890.123456").

    Raises:
        SlackAPIError: If the channel does not exist or the bot lacks access.

    Constraints:
        Requires channels:write OAuth scope. Rate-limited to 1 message/second
        per channel. text must be non-empty.

    Stability: stable

    MCP:
        Use this tool to post notifications, alerts, or status updates.
        Do not use for interactive conversations.
    """
```

### Passing — canonical empty section satisfies requirement

```python
def run_migration(dry_run: bool) -> None:
    """Apply pending schema migrations.

    Args:
        dry_run: If True, validate without applying changes.

    Returns:
        None.

    Raises:
        MigrationError: If a migration fails mid-run. The database is left
            in a partially migrated state; manual intervention required.
    """
```

## Rationale

Required sections exist because agents need specific information to call a function safely. A Tier 3 MCP tool without a `Constraints` section leaves the agent guessing about preconditions. A Tier 2 function without `Returns` leaves it guessing about the return value. DOC012 makes these omissions visible before code ships.

## Configuration

Disable globally:

```toml
[tool.docpact]
ignore = ["DOC012"]
```

Disable for a specific section across the project (not supported directly — use per-file-ignores or inline suppression).

Suppress inline (on the `def` line):

```python
def publish(  # nodo: DOC012 -- Constraints section pending, tracked in #88
    event: dict,
) -> None: ...
```
