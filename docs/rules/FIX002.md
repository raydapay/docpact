# FIX002 — Suppression names codes but has no -- reason

**Namespace:** `FIX`  
**Severity:** 🟡 warning  
**Fix:** No automatic fix

---

## Description

Fires when a suppression comment names specific rule codes but has no `-- reason` clause. A code list tells reviewers what was suppressed; the reason tells them why. Without it, the suppression is an unexplained override.

The `-- reason` separator is two hyphens followed by at least one non-whitespace character. Whitespace between the code list and `--` is allowed.

```python
# nodo: DOC001             ← FIX002 fires (codes, no reason)
# nodo: DOC001 --          ← FIX002 fires (-- present, reason empty)
# nodo: DOC001 -- reason   ← passes
```

FIX002 is a line-level rule. Bare suppressions (no codes at all) are FIX001's domain — FIX002 only fires when codes are present.

The FIX namespace is opt-in. Add `"FIX"` to your `select` list:

```toml
[tool.docpact]
select = ["DOC", "MCP", "FIX"]
```

## Examples

### Triggering

```python
def build_payload(  # nodo: DOC007
    params: dict,
) -> dict:
    """Build request payload."""
```

FIX002 fires: `DOC007` is named but no `-- reason` is provided.

### Passing

```python
def build_payload(  # nodo: DOC007 -- params dict is intentionally variadic, see ADR-007
    params: dict,
) -> dict:
    """Build request payload."""
```

### Multiple codes — still requires one reason

```python
def legacy(  # nodo: DOC001, DOC012 -- pre-docpact code, tracked in #99
    x: int,
) -> int: ...
```

## Rationale

A suppression with codes but no reason answers "what" but not "why." Six months later, no one remembers whether `DOC007` was suppressed because the parameter was intentionally undocumented, because the docstring predates the parameter rename, or because someone was in a hurry. The reason is the part that decays — and the part that makes suppressions reviewable.

## Configuration

Disable globally:

```toml
[tool.docpact]
ignore = ["FIX002"]
```

FIX002 applies its own standard to itself: `# nodo: FIX002 -- reason` is a valid suppression.

```python
def internal(  # nodo: FIX002 -- this module is excluded from reason requirements
    x: int,
) -> int: ...
```
