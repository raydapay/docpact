# DOC013 — Empty section uses non-canonical form; should be 'None.'

**Namespace:** `DOC`  
**Severity:** 🟡 warning  
**Fix:** No automatic fix

---

## Description

Fires when a docstring section exists but has an empty or near-empty body that uses a non-canonical form. The canonical way to explicitly document that a section has nothing to say is `None.` — a single sentence ending with a period.

Non-canonical forms that trigger DOC013:

- Blank body (section header with no content)
- `N/A`
- `NA`
- `None` (without the trailing period)

Sections that have structured entries (e.g. an Args section with parameter lines) are never flagged by DOC013, even if the entries are sparse.

DOC013 is distinct from DOC012. DOC012 fires when a required section is entirely absent. DOC013 fires when a section exists but uses an informal empty form. Both can fire independently.

## Examples

### Triggering

```python
def close_connection(conn: Connection) -> None:
    """Close the database connection.

    Args:
        conn: The connection to close.

    Returns:
        N/A  # non-canonical — DOC013 fires

    Raises:
        # blank body — DOC013 fires
    """
```

### Passing

```python
def close_connection(conn: Connection) -> None:
    """Close the database connection.

    Args:
        conn: The connection to close.

    Returns:
        None.

    Raises:
        None.
    """
```

## Rationale

`None.` is the only form that reads unambiguously as "I considered this section and there is nothing to say." `N/A` and blank bodies are ambiguous — they might mean "not applicable," "forgot to fill this in," or "this section is a stub." Consistent use of `None.` makes the intent clear and allows tooling to distinguish deliberate absence from accidental omission.

## Configuration

Disable globally:

```toml
[tool.docpact]
ignore = ["DOC013"]
```

Suppress inline (on the `def` line):

```python
def flush(  # nodo: DOC013 -- legacy docstring style, updating separately
    buffer: bytes,
) -> None: ...
```
