# DOC007 — Args section inconsistent with function signature

**Namespace:** `DOC`  
**Severity:** 🔴 error  
**Fix:** No automatic fix

---

## Description

Fires when the Args section of a docstring is inconsistent with the function signature. There are two sub-cases, both reported as DOC007:

**Sub-case 1 — parameter in signature absent from Args.**  
A positional or keyword parameter appears in the signature but has no corresponding entry in Args. Only fires at Tier 2+ (Tier 1 treats Args as recommended, not required). `self`, `cls`, `*args`, and `**kwargs` are excluded from this check — they are optional to document. If `*args` or `**kwargs` are documented, their names must still match (sub-case 2 applies).

**Sub-case 2 — phantom parameter documented in Args.**  
An entry in Args names a parameter that does not exist in the signature. Fires at all tiers. This is the most common form of DOC007: a parameter was renamed in the code but the docstring was not updated.

No fix is provided because the mismatch is ambiguous — docpact cannot determine whether the parameter was renamed, removed, or simply forgotten. DOC014 fires alongside when a phantom name closely resembles a real parameter (likely typo).

## Examples

### Triggering — phantom parameter (rename missed)

```python
def charge(account_id: str, amount_cents: int) -> str:
    """Charge the account.

    Args:
        account_id: UUID of the account to charge.
        amount: Amount to charge in dollars.  # was renamed to amount_cents

    Returns:
        Transaction ID.
    """
```

DOC007 fires: `'amount'` documented in Args but absent from signature.  
DOC014 also fires: `'amount'` looks like a typo of `'amount_cents'`.

### Triggering — required parameter undocumented

```python
def charge(account_id: str, amount_cents: int, currency: str) -> str:
    """Charge the account.

    Args:
        account_id: UUID of the account to charge.
        amount_cents: Amount to charge in cents.
        # currency parameter missing from Args

    Returns:
        Transaction ID.
    """
```

DOC007 fires: `'currency'` present in signature but absent from Args.

### Passing

```python
def charge(account_id: str, amount_cents: int, currency: str) -> str:
    """Charge the account.

    Args:
        account_id: UUID of the account to charge.
        amount_cents: Amount to charge in cents. Must be positive.
        currency: ISO 4217 currency code. Must be supported by the processor.

    Returns:
        Transaction ID.
    """
```

### Passing — `*args` and `**kwargs` undocumented (allowed)

```python
def log(*args: str, **kwargs: object) -> None:
    """Log a message.

    No Args section needed for *args/**kwargs if contents are not meaningful.
    """
```

## Rationale

A stale Args section is a silent lie. When `amount` was renamed to `amount_cents` six weeks ago, every agent calling that function has been constructing the wrong payload. DOC007 makes this class of drift a gate, not a review comment.

## Configuration

Disable globally:

```toml
[tool.docpact]
ignore = ["DOC007"]
```

Disable per file:

```toml
[tool.docpact.per-file-ignores]
"tests/fixtures/*" = ["DOC007"]
```

Suppress inline (on the `def` line):

```python
def legacy_api(  # nodo: DOC007 -- docstring predates rename, tracked in #210
    user_id: str,
    amount_cents: int,
) -> dict: ...
```
