# MCP001 — Both decorator description= and docstring MCP: section present

**Namespace:** `MCP`  
**Severity:** 🔴 error  
**Fix:** No automatic fix

---

## Description

Fires when an MCP tool function has both a `description=` keyword argument on its decorator and an `MCP:` section in its docstring. FastMCP accepts both forms; when they differ, only one propagates to the runtime schema — the other drifts silently.

MCP decorator names checked: `mcp.tool`, `mcp.resource`, `mcp.prompt`, `tool`, `resource`, `prompt`.

The preferred resolution is to use the docstring `MCP:` section as the single source and remove the decorator `description=`. The docstring travels with the code; the decorator argument is a redundant override that can diverge on the next rename.

## Examples

### Triggering

```python
@mcp.tool(description="Send a Slack message to a channel.")
def send_message(channel: str, text: str) -> str:
    """Send a Slack message to a channel.

    Args:
        channel: Slack channel name, including the # prefix.
        text: Message text. Markdown supported.

    Returns:
        Message timestamp.

    Raises:
        SlackAPIError: If the channel does not exist.

    Constraints:
        Requires channels:write OAuth scope. Rate-limited to 1 message/second.

    Stability: stable

    MCP:
        Use this tool to post notifications and status updates to Slack.
        Do not use for interactive conversations or DMs.
    """
```

MCP001 fires: both `description=` and the `MCP:` section are present.

### Passing — decorator description= only (simple case)

```python
@mcp.tool(description="Send a Slack message to a channel.")
def send_message(channel: str, text: str) -> str:
    """Send a Slack message to a channel.

    Args:
        channel: Slack channel name, including the # prefix.
        text: Message text. Markdown supported.

    Returns:
        Message timestamp.

    Raises:
        None.

    Constraints:
        None.

    Stability: stable
    """
```

### Passing — MCP: section only (recommended for Tier 3)

```python
@mcp.tool
def send_message(channel: str, text: str) -> str:
    """Send a Slack message to a channel.

    Args:
        channel: Slack channel name, including the # prefix.
        text: Message text. Markdown supported.

    Returns:
        Message timestamp.

    Raises:
        SlackAPIError: If the channel does not exist or the bot lacks access.

    Constraints:
        Requires channels:write OAuth scope. Rate-limited to 1 message/second
        per channel.

    Stability: stable

    MCP:
        Use this tool to post notifications and status updates to Slack.
        Do not use for interactive conversations or DMs.
    """
```

## Rationale

Two sources of MCP description is one too many. When they agree, it's harmless redundancy. When they diverge — typically after refactoring — the runtime schema reflects whichever form FastMCP prioritizes, while the other silently misleads readers. MCP001 forces a single source of truth before the divergence becomes a runtime problem.

## Configuration

Disable globally:

```toml
[tool.docpact]
ignore = ["MCP001"]
```

Suppress inline (on the `def` line):

```python
@mcp.tool(description="Legacy description kept for compatibility.")
def legacy_tool(  # nodo: MCP001 -- decorator description= frozen by SDK version constraint
    x: str,
) -> str: ...
```
