# DOC052 — Examples section absent (require_examples_min_tier is set)

**Namespace:** `DOC`  
**Severity:** 🔴 error  
**Fix:** Safe fix available (`--fix`)

---

## Description

DOC052 fires when a function's tier is at or above `require_examples_min_tier`
and its docstring has no `Examples:` section.

**Off by default.** The rule only activates once `require_examples_min_tier` is
set in `[tool.docpact]`. It is intended for codebases where an `Examples:` block
is the highest-signal section for the reader:

- MCP-first / tool-calling code — set it to `3` so every Tier-3 tool surface
  carries a worked example for the calling agent.
- Teams that want examples across all public API — set it to `2`.

The safe fix (`--fix`) appends an `Examples:` stub terminated with a `[FILL]`
marker at the end of the docstring body. As with every docpact stub, `[FILL]` is
the signal to write a real example — replacing it with filler defeats the rule's
purpose (see CLAUDE.md, "Structural enforcement vs. semantic content").

## Examples

Assume the project sets:

```toml
[tool.docpact]
require_examples_min_tier = 3
```

### Triggering

A Tier-3 function (e.g. an MCP tool) with no `Examples:` section:

```python
def search_transactions(query: str) -> list[dict]:
    """Search transactions by full-text match.

    Args:
        query: Full-text match against the transaction description.

    Returns:
        Matching transaction records, most recent first.
    """
```

```
tools.py:1:1: DOC052 Tier 3 function missing Examples section
```

### Passing

```python
def search_transactions(query: str) -> list[dict]:
    """Search transactions by full-text match.

    Args:
        query: Full-text match against the transaction description.

    Returns:
        Matching transaction records, most recent first.

    Examples:
        >>> search_transactions("coffee")
        [{"id": "tx_1", "amount": 4.50, "description": "Coffee"}]
    """
```

A function below the configured tier never triggers, regardless of whether it has
examples.

## Configuration

```toml
[tool.docpact]
require_examples_min_tier = 3   # enables DOC052 for Tier 3+ functions
```

Disable the rule entirely:

```toml
[tool.docpact]
ignore = ["DOC052"]
```

Or suppress inline for a single function:

```python
def my_function(  # nodo: DOC052 -- reason
    ...
```
