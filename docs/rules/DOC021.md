# DOC021 — "Defaults to X" in Args prose does not match the signature default

**Namespace:** `DOC`  
**Severity:** 🟡 warning  
**Fix:** No automatic fix

---

## Description

A `Defaults to <value>` phrase in an Args entry asserts something checkable: that
the documented default equals the parameter's actual default in the signature.
DOC021 fires when they drift — the classic stale-docstring bug where the code's
default changed but the prose did not (or vice versa).

No auto-fix: a mismatch could mean either the code or the docstring is wrong, and
choosing which to correct requires human judgement.

DOC021 fires only when **all** of these hold:

- The parameter has a default in the signature.
- That default is a Python literal — `str`, `int`, `float`, `bool`, or `None`.
- The description contains a `Defaults to` phrase.
- The extracted value does not match the signature default.

Comparison is lenient where it should be: surrounding quotes and rST `` ``backtick`` ``
markup are stripped, and `True`/`False`/`None` compare case-insensitively (Python
capitalizes them; prose conventionally does not).

### Literal-only scope (a deliberate blind spot)

DOC021 stays silent when the effective default is a name reference such as
`DEFAULT_TIMEOUT` or `SESSION_REGISTRY`. docpact cannot resolve a constant's
value without importing the module, which it never does. Authors also legitimately
write `"Defaults to the session registry"` rather than naming the variable, so
firing here would force an arbitrary choice between naming and describing.
Restricting to literals removes that whole ambiguous class and keeps the rule
actionable.

### FastAPI / wrapper defaults

When the signature default is a single-argument call like `Query(False)` or
`Field("hello")`, the *effective* documented default is the inner literal
(`False` / `"hello"`), not the call expression. DOC021 unwraps it before
comparing, so it does not systematically false-positive on FastAPI routes.

## Examples

### Triggering

```python
def fetch(count: int = 5) -> list:
    """Fetch items.

    Args:
        count: Number of items to fetch. Defaults to 10.
    """
```

```
mod.py:1:1: DOC021 Parameter 'count': docstring says 'Defaults to 10' but signature default is '5'
```

### Passing

The prose matches the signature; the FastAPI wrapper is unwrapped to its inner
literal:

```python
def fetch(count: int = 5, verbose: bool = Query(False)) -> list:
    """Fetch items.

    Args:
        count: Number of items to fetch. Defaults to 5.
        verbose: Whether to include detail. Defaults to False.
    """
```

A name-reference default is out of scope and never fires:

```python
def fetch(timeout=DEFAULT_TIMEOUT) -> list:
    """Fetch items.

    Args:
        timeout: Seconds before giving up. Defaults to 30.
    """
```

## Configuration

This rule can be disabled with:

```toml
[tool.docpact]
ignore = ["DOC021"]
```

Or suppressed inline:

```python
def my_function(  # nodo: DOC021 -- reason
    ...
```
