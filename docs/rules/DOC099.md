# DOC099 — [FILL] placeholder marker not replaced

**Namespace:** `DOC`  
**Severity:** 🔴 error  
**Fix:** No automatic fix

---

## Description

Fires when a docstring contains a `[FILL` marker, indicating that a stub generated by DOC001's `--fix` has not been completed. Stubs are starting points, not finished docstrings — DOC099 ensures they cannot pass the pipeline unmodified.

Any text beginning with `[FILL` anywhere in the raw docstring triggers DOC099, including in parameter descriptions, the summary line, or section bodies.

DOC099 is the intentional second half of DOC001's fix cycle:

1. DOC001 fires on a missing docstring.
2. `docpact check --fix` inserts a stub with `[FILL]` markers.
3. DOC099 fires on the stub.
4. The author fills in the markers with real content.
5. DOC099 stops firing.

## Examples

### Triggering — unfilled stub

```python
def process_payment(amount_cents: int, currency: str) -> dict:
    """[FILL: single-sentence summary in imperative mood]

    Args:
        amount_cents: [FILL]
        currency: [FILL]

    Returns:
        [FILL]
    """
```

DOC099 fires (multiple `[FILL]` markers present).

### Passing — stub filled with real content

```python
def process_payment(amount_cents: int, currency: str) -> dict:
    """Authorize and capture a payment via the configured processor.

    Args:
        amount_cents: Amount to charge in cents. Must be positive.
        currency: ISO 4217 currency code. Must be supported by the processor.

    Returns:
        Transaction receipt with transaction_id, settled_at, and status.
    """
```

## Rationale

Cargo-cult compliance — replacing `[FILL]` with `x: The x value.` — is always an option, but it's hard to do accidentally. The `[FILL]` marker is deliberately unusual text that forces a conscious decision to either write real content or explicitly suppress the rule with a documented reason.

## Configuration

Disable globally (not recommended — defeats the stub workflow):

```toml
[tool.docpact]
ignore = ["DOC099"]
```

Suppress inline when a stub is intentionally incomplete (e.g., during a large migration):

```python
def legacy_handler(  # nodo: DOC099 -- stub in progress, tracked in #301
    request: dict,
) -> dict:
    """[FILL: legacy API handler]

    Args:
        request: [FILL]

    Returns:
        [FILL]
    """
```
