# SEM002 — Module docstring is semantically weak (advisory; module scan)

**Namespace:** `SEM`  
**Severity:** 🟡 warning  
**Fix:** No automatic fix

---

## Description

SEM002 is the module-level companion to [SEM001](SEM001.md):
[DOC002](DOC002.md) guarantees a module docstring *exists*; SEM002 judges whether
it is *useful*. It fires when a module docstring is either:

- **Out of scope with the module's public symbols** — it describes a purpose the
  symbols do not support, or names something the module does not actually contain.
- **Pure boilerplate** — `"Utilities."`, `"The widgets module."`, and similar
  filler that orients no reader.

The rubric is deliberately narrow: it judges **scope consistency and
orientation**, **never completeness**. SEM002 will not flag a docstring for
failing to enumerate every public symbol — a module summary is not an index. Its
input is the docstring plus the list of public symbols; it does not read
`context_files`.

Produced by `docpact semantic` in module scan mode via an LLM, so it is
**non-deterministic and advisory**, and **never** part of `docpact check`. It is
**opt-in** even within `semantic` (function scan is the default).

> **Model-sensitive (ADR-013): reliable only on a gpt-4o-class model.** On weaker
> models (e.g. gpt-4o-mini) it produced **43–71% false positives** by wrongly
> demanding symbol enumeration; on gpt-4o, 0%. Do not run module scan without a
> capable model.

## Examples

### Triggering

A module whose docstring is pure boilerplate while its symbols clearly do
specific work:

```python
"""Utilities."""

def parse_iso8601(text: str) -> datetime: ...
def to_unix_millis(dt: datetime) -> int: ...
def humanize_duration(seconds: int) -> str: ...
```

```
$ docpact semantic mod.py --scan-modes module
mod.py:1: SEM002 weak — boilerplate docstring; module provides datetime parsing/formatting helpers. (model=gpt-4o, prompt=builtin:1c8d…)
```

### Passing

The docstring orients the reader to what the module is for, consistent with its
symbols — without listing them:

```python
"""Parse and format timestamps at the system's boundaries.

Conversions between ISO-8601 text, timezone-aware datetimes, and the Unix
millisecond integers used by the storage layer. Import these rather than
hand-rolling format strings at call sites.
"""

def parse_iso8601(text: str) -> datetime: ...
def to_unix_millis(dt: datetime) -> int: ...
def humanize_duration(seconds: int) -> str: ...
```

## Configuration

SEM002 is off until you enable module scan, and advisory even then:

```toml
[tool.docpact.semantic]
scan_modes = ["function", "module"]   # add "module" to run SEM002
finding_threshold = "weak"            # "weak" (default) | "empty"

[tool.docpact.rules]
SEM002 = "error"                      # raise severity if you want it to gate
```

Or enable module scan for a single run:

```bash
docpact semantic src/ --scan-modes module
```

> SEM002 is module-level, so the inline `# nodo: SEM002` suppression that works
> for function rules does not apply. Control it through `scan_modes`, the
> per-rule severity above, or `ignore = ["SEM002"]`.
