## Description

**DOC098 is permanently out of scope. This code is reserved and never fires.**

The code exists to prevent reuse of a meaningful-sounding error number. The check function is permanently empty.

### Why doctest execution is out of scope

Executing docstring Examples sections as doctests has unavoidable side effects: network calls, file writes, database mutations, subprocess spawns. There is no safe sandboxing strategy for a structural linter that:

1. Must not import the code it analyzes (see [architecture invariants](../../CLAUDE.md#key-invariants))
2. Must not require a live runtime environment
3. Must not produce different results based on external state

docpact checks structure, not behavior. Doctest execution is behavior verification — it belongs in the test suite, not in the linter.

### Alternative

If you need doctest verification, use Python's built-in doctest module:

```bash
python -m doctest src/your_module.py
pytest --doctest-modules src/
```

## Configuration

DOC098 cannot be selected, ignored, or suppressed — it never fires. If `DOC098` appears in your `select` or `ignore` lists it is silently harmless.
