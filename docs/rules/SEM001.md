# SEM001 — Docstring is semantically weak/empty (advisory; `docpact semantic`)

**Namespace:** `SEM`  
**Severity:** 🟡 warning  
**Fix:** No automatic fix

---

## Description

SEM001 is the meaning-level check the deterministic `check` rules cannot perform.
It flags a docstring that is structurally complete but carries no real signal:

- **Cargo-cult restatement** — every field merely echoes the parameter name
  (`user_id: The user id.`), telling a reader nothing the type annotation did not.
- **Hidden contract** — a precondition, constraint, or side effect the
  implementation clearly has but the docstring never surfaces.
- **Empty Returns** — a `Returns:` that only restates the return type.

It is produced by `docpact semantic` via an LLM, so it is **non-deterministic and
advisory**. It is **never** part of `docpact check`, `make verify`, or the
dogfood pass — `check`'s reproducibility is untouched. The verdict vocabulary is
`good` / `weak` / `empty`; SEM001 fires on `weak` and `empty` (the
`finding_threshold` setting decides which of those count).

Because behavior tracks the `(model, prompt)` pair rather than pinned code,
SEM codes guarantee a stable **intent**, not stable **output** (ADR-015). Every
`semantic` run reports the `model=<id>` and a prompt fingerprint (`builtin:<hash>`)
in both text and JSON so a result is always traceable to what produced it.

## Examples

### Triggering

Structure is present, signal is not — every field restates the signature:

```python
def process(user_id: str, flags: int) -> dict:
    """Process.

    Args:
        user_id: The user id.
        flags: The flags.

    Returns:
        The result.
    """
```

```
$ docpact semantic mod.py
mod.py:1: SEM001 weak — Args restate parameter names; Returns restates the type. (model=gpt-4o, prompt=builtin:9f3a…)
```

### Passing

The same signature, documented with what the signature cannot convey —
preconditions, the meaning of the bitmask, what the return value is *for*:

```python
def process(user_id: str, flags: int) -> dict:
    """Apply pending transforms to a user account.

    Args:
        user_id: UUID of the user record. Must exist in the user table;
            raises ValueError if not found.
        flags: Bitmask of FeatureFlag values. Unknown bits are silently
            ignored for forward compatibility.

    Returns:
        Snapshot of the account state after all transforms applied, keyed by
        field name. Diff against the prior snapshot to see what changed.
    """
```

## Configuration

SEM001 runs only under `docpact semantic` and is advisory there — it does not
affect the exit code by default. To make a semantic run gate CI, opt in
explicitly:

```toml
[tool.docpact.semantic]
finding_threshold = "weak"   # "weak" (default) flags weak+empty; "empty" flags only empty

[tool.docpact.rules]
SEM001 = "error"             # raise severity if you want it to gate
```

Scope a run to a pull request's changed files:

```bash
docpact semantic src/ --changed-only origin/main
```

Inspect the exact prompt without an API call:

```bash
docpact semantic src/ --dry-run
```
