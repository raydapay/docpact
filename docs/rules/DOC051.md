# DOC051 — Constraints section duplicates Annotated metadata

**Namespace:** `DOC`  
**Severity:** 🔴 error  
**Fix:** No automatic fix

---

## Description

Fires when a function's Constraints section in prose repeats a constraint already encoded in a parameter's `Annotated[...]` type annotation. Constraints expressible in the type system belong there — not duplicated in documentation where they can drift.

**Detection heuristic:**

Numeric values are extracted from common constraint metadata in `Annotated` parameters:

| Metadata function | Example |
|---|---|
| `MaxLen(N)` | `Annotated[str, MaxLen(4096)]` |
| `MinLen(N)` | `Annotated[str, MinLen(1)]` |
| `Ge(N)`, `Le(N)`, `Gt(N)`, `Lt(N)` | `Annotated[int, Ge(0)]` |
| `max_length=N` | `Annotated[str, Field(max_length=100)]` |
| `min_length=N` | `Annotated[str, Field(min_length=1)]` |
| `max_digits=N`, `min_digits=N` | similarly |

When the extracted numeric value appears anywhere in the Constraints section body, DOC051 fires. This heuristic catches the most common duplication patterns.

## Examples

### Triggering

```python
from typing import Annotated
from annotated_types import MaxLen


def create_post(
    content: Annotated[str, MaxLen(4096)],
) -> str:
    """Create a post.

    Args:
        content: The post body text.

    Returns:
        Post ID.

    Constraints:
        content must not exceed 4096 characters.  # duplicates MaxLen(4096)

    Stability: stable
    """
```

DOC051 fires: `'MaxLen(4096)'` duplicated in Constraints prose.

### Passing — constraint in annotation only

```python
from typing import Annotated
from annotated_types import MaxLen, MinLen


def create_post(
    content: Annotated[str, MinLen(1), MaxLen(4096)],
) -> str:
    """Create a post.

    Args:
        content: Post body text. HTML is stripped before storage.

    Returns:
        Post ID.

    Constraints:
        Caller must be authenticated. Posts are rate-limited to 10/minute
        per user.

    Stability: stable
    """
```

### Passing — prose-only constraint (no Annotated value)

```python
def withdraw(account_id: str, amount_cents: int) -> dict:
    """Withdraw funds from an account.

    Args:
        account_id: UUID of the account.
        amount_cents: Amount to withdraw in cents.

    Returns:
        Updated account balance.

    Constraints:
        Account must have sufficient balance. Accounts in frozen status
        cannot be withdrawn from. Minimum withdrawal is 100 cents.

    Stability: stable
    """
```

## Rationale

When a constraint is encoded in `Annotated[...]`, it is enforced by the runtime type system and visible to static analyzers. Repeating it in the Constraints section creates a second source of truth that can drift: the annotation gets updated, the prose doesn't, and the documentation describes a constraint that no longer matches the code. DOC051 keeps constraints in one place.

## Configuration

Disable globally:

```toml
[tool.docpact]
ignore = ["DOC051"]
```

Suppress inline (on the `def` line):

```python
def send(  # nodo: DOC051 -- constraint repeated for human readability at Tier 3
    message: Annotated[str, MaxLen(2000)],
) -> None: ...
```
