# DOC051 — Constraints section duplicates Annotated metadata

> **Status: Deferred.** The concept is sound; the implementation is not ready.
> Code DOC051 is reserved. See PROGRESS.md "Deferred with reasoning" and spec §5.3.

**Namespace:** `DOC`  
**Severity:** 🔴 error (planned)  
**Fix:** Planned (remove duplicating prose entry)

---

## Concept

When a constraint is already encoded in `Annotated[T, ...]` (e.g., `MaxLen(4096)`,
`Ge(0)`, `Pattern(r"...")`), it is enforced at the type level and visible to static
analyzers. Repeating it in the `Constraints:` section creates a second source of
truth that can drift. DOC051 is designed to catch this.

The key boundary:

- **Type annotation** (`Annotated[T, ...]`, `Literal[...]`, `T | None`) — value
  properties, enforced at runtime or by the type checker.
- **`Constraints:` section** — external-world conditions: business rules, SLAs,
  ADR references, operational limits, deployment risks. Things the type system
  cannot encode.

If a constraint belongs in `Annotated`, it should *only* be there. If it belongs
in `Constraints:`, it is almost certainly not type-expressible at all.

## Why deferred

The shipped heuristic — extract numeric values from `MaxLen(N)`, `Ge(N)`, etc.;
check if that number appears anywhere in the `Constraints:` body — produces false
positives on legitimate code. The same number may appear in both contexts for
different reasons: the annotation enforces the technical bound, the Constraints
entry names the business authority ("4096 per API contract — see ADR-012").
A numeric substring match cannot distinguish these cases.

To implement correctly, DOC051 needs semantic matching: comparing what the
annotation constraint *means* against what the Constraints prose *says*.
Candidate approaches (none ready): AST-level structured comparison, NLP phrase
similarity, or a structured Constraints format with machine-readable fields.

## Planned examples

### Will fire — pure duplication

```python
from typing import Annotated
from annotated_types import MaxLen


def create_post(
    content: Annotated[str, MaxLen(4096)],
) -> str:
    """Create a post.

    Args:
        content: The post body text.

    Returns:
        Post ID.

    Constraints:
        content must not exceed 4096 characters.

    Stability: stable
    """
```

`content must not exceed 4096 characters` restates what `MaxLen(4096)` already
enforces. DOC051 will fire here once implemented.

### Will not fire — annotation + external rationale

```python
def create_post(
    content: Annotated[str, MaxLen(4096)],
) -> str:
    """Create a post.

    Args:
        content: Post body text. HTML is stripped before storage.

    Returns:
        Post ID.

    Constraints:
        Caller must hold an active session. Posts are rate-limited to
        10/minute per user (per ADR-031). Storage backend enforces a
        hard limit of 4096 bytes; exceeding it raises StorageError.

    Stability: stable
    """
```

The "4096" in Constraints references the storage backend behavior, not the
annotation. The annotation and the Constraints entry serve different audiences.

### Will not fire — Constraints has no type-expressible overlap

```python
def withdraw(account_id: str, amount_cents: int) -> dict:
    """Withdraw funds from an account.

    Args:
        account_id: UUID of the account.
        amount_cents: Amount in cents.

    Returns:
        Updated account balance snapshot.

    Constraints:
        Account must have sufficient balance. Accounts in frozen status
        cannot be withdrawn from. Minimum withdrawal is 100 cents
        (regulatory requirement — see compliance/policy.md).

    Stability: stable
    """
```

No `Annotated` metadata present; all Constraints entries are operational.

## Rationale

When a constraint is in `Annotated[...]`, it is enforced by the runtime and
visible to tools. Prose that restates it is noise — it adds a drift surface
without adding information. DOC051's job is to keep the annotation the
single source of truth for value-level constraints, and `Constraints:` the
single source of truth for world-level constraints.
