# REG010 — Tool Args section out of parity with its input model

**Namespace:** `REG`  
**Severity:** 🟡 warning  
**Fix:** No automatic fix

---

## Description

A tool-registry entry that names a Pydantic model as its `input_model` and
documents parameters in its description's `Args:` section is asserting two
things that must agree: the documented args and the model's actual fields.
REG010 fires when they drift — a model field the `Args:` omit, or a documented
arg with no matching model field. It is the registry counterpart of DOC007's
phantom/missing-parameter check.

REG010 has two legs, and both require only that `REG` is in `select`:

- **Same-file (ADR-012)** — when the `input_model` is a class defined in the
  **same file** as the registry entry, docpact reads its fields by a static AST
  pass and checks parity **offline, in the default `docpact check`**. No
  language server, no `--crossfile`.
- **Cross-file (ADR-009/ADR-010)** — when the `input_model` is **imported** from
  another module, docpact resolves it through a language server
  (`[tool.docpact.lsp]`, default `ty`) and runs the same check. This leg runs
  **only under `docpact check --crossfile`**; a model the server cannot resolve
  is skipped (under-enforce, never guess), and a missing/failing server degrades
  gracefully.

Either way docpact never imports or executes your code — the model's fields are
read by static AST.

To disable the same-file leg without disabling the rule entirely (it is on by
default once `REG` is selected), set `REG010 = "off"` under
`[tool.docpact.rules]`.

## Examples

### Same-file — model and registry in one module (offline)

```python
# tools.py
from pydantic import BaseModel


class SearchInput(BaseModel):
    query: str
    limit: int


register_tool(ToolSpec(
    name="search",
    input_model=SearchInput,
    description=(
        "Search transactions.\n\n"
        "Args:\n"
        "    query: Full-text match against the description.\n"
        # 'limit' is a field of SearchInput but is not documented here
    ),
    service_function=search_handler,
))
```

Run with plain `docpact check tools.py` (and `REG` selected):

```
tools.py:10:14: REG010 input model 'SearchInput' field 'limit' is not documented in tool 'search' Args section
```

### Cross-file — model imported from another module (`--crossfile`)

The examples below live in different files, so they need the language-server leg.

#### Triggering — a model field the docs omit

```python
# schemas.py
from pydantic import BaseModel


class SearchInput(BaseModel):
    query: str
    limit: int
```

```python
# tools.py
from schemas import SearchInput

TOOLS = [
    ToolDefinition(
        name="search",
        input_model=SearchInput,
        description=(
            "Search transactions.\n\n"
            "Args:\n"
            "    query: Full-text match against the description.\n"
            # 'limit' is a field of SearchInput but is not documented here
        ),
    ),
]
```

Run with `docpact check . --crossfile` (and `REG` selected):

```
tools.py:4:4: REG010 input model 'SearchInput' field 'limit' is not documented in tool 'search' Args section
```

The reverse direction fires too — a documented arg with no matching model field:

```
tools.py:4:4: REG010 tool 'search' Args entry 'offset' has no matching field in input model 'SearchInput'
```

#### Passing — Args and model fields match

```python
# tools.py
TOOLS = [
    ToolDefinition(
        name="search",
        input_model=SearchInput,  # fields: query, limit
        description=(
            "Search transactions.\n\n"
            "Args:\n"
            "    query: Full-text match against the description.\n"
            "    limit: Maximum number of results to return.\n"
        ),
    ),
]
```

## Configuration

The same-file leg needs only the `REG` namespace; the cross-file leg
additionally needs `--crossfile` and a language server.

```toml
[tool.docpact]
select = ["DOC", "REG"]   # REG010 needs the REG namespace

[tool.docpact.lsp]
server = ["ty", "server"]  # only for the cross-file leg; swappable
```

```bash
docpact check src/             # same-file parity, offline
docpact check src/ --crossfile # adds imported-model parity
```

Disable it specifically:

```toml
[tool.docpact]
ignore = ["REG010"]
```

Or suppress inline, on the registry entry's line:

```python
TOOLS = [
    ToolDefinition(name="search", input_model=SearchInput,  # nodo: REG010 -- schema is intentionally narrower
        description="..."),
]
```
