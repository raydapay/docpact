# DOC014 — Documented parameter name is a likely typo of a real parameter

**Namespace:** `DOC`  
**Severity:** 🟡 warning  
**Fix:** No automatic fix

---

## Description

Fires when a documented parameter name is absent from the signature but closely resembles a real parameter. Similarity is measured using `difflib.get_close_matches` with a cutoff of 0.6 — roughly edit distance 1–2 for typical parameter names.

DOC014 is a warning-level companion to DOC007. DOC007 fires for any phantom parameter regardless of similarity. DOC014 adds the "did you mean?" hint when a likely typo is detected. Both rules can fire on the same parameter.

No fix is available: the correct resolution requires knowing whether the parameter was renamed in the code, renamed in the docstring, or is genuinely wrong on both sides.

## Examples

### Triggering — rename missed in docstring

```python
def process_payment(amount_cents: int, currency: str) -> str:
    """Process a payment.

    Args:
        amount: Amount to charge.  # was 'amount_cents' — typo detected
        currency: ISO 4217 code.

    Returns:
        Transaction ID.
    """
```

DOC007 fires: `'amount'` documented but absent from signature.  
DOC014 fires: `'amount'` not in signature; did you mean `'amount_cents'`?

### Triggering — transposition typo

```python
def send(recipeint: str, body: str) -> None:
    """Send a message.

    Args:
        recipeint: Email address of the recipient.  # typo of 'recipient'
        body: Message body.
    """
```

DOC014 fires: `'recipeint'` not in signature; did you mean `'recipient'`?

### Passing

```python
def process_payment(amount_cents: int, currency: str) -> str:
    """Process a payment.

    Args:
        amount_cents: Amount to charge in cents. Must be positive.
        currency: ISO 4217 currency code.

    Returns:
        Transaction ID.
    """
```

## Rationale

Rename-without-updating-docstring is the most common cause of phantom parameters. DOC007 catches the problem; DOC014 adds the context needed to fix it quickly. Without the hint, the reviewer must manually compare documented names to signature names to find the rename.

## Configuration

Disable globally:

```toml
[tool.docpact]
ignore = ["DOC014"]
```

Suppress inline (on the `def` line):

```python
def adapt(  # nodo: DOC014 -- legacy alias documented intentionally
    src: str,
    dst: str,
) -> None: ...
```
